# 영어 학습 UX 개선과 검증

초등학교 입학 전후 아이가 혼자 시작하기 쉽고, 틀려도 계속할 수 있고, 배운 말을 다시 꺼내 쓸 수 있는 흐름을 기준으로 개선했다.

## 관찰과 반영

| 관찰                                                            | 개선                                                                     | 확인 방법                                                          |
| --------------------------------------------------------------- | ------------------------------------------------------------------------ | ------------------------------------------------------------------ |
| 첫 모험 버튼이 항상 soccer 상세 화면으로 연결됨                 | 완료 기록에 맞춰 세 단어를 추천하고 사진·듣기 중심 탐험으로 시작         | 신규 사용자는 soccer/dog/apple, 이후 오답·복습일·새 단어 순서 검사 |
| 5문제 문장 퀴즈부터 시작하면 읽기 부담이 큼                     | 소리 듣기 → 실사 사진 찾기 → 짧은 문장 따라 말하기, 세 단어로 종료       | 오답 후 재선택, 듣기 없이 힌트로 완주, 말하기 표시 없이 완주       |
| 단어 연습 뒤 다음에 무엇을 할지 불명확                          | 첫 탐험·이어 하기·다시 만날 단어를 홈에 표시, 결과에서 다음 학습 연결    | 홈·결과·사진 상세·동화·게임 이동                                   |
| 중간에 나가면 처음부터 해야 함                                  | 다음 단어로 넘어간 결과와 세 단어 목록을 프로필에 저장                   | 쉬기·새로고침 후 두 번째 단어부터 복원, 미완료 도장 없음           |
| 오답 기록이 다음 학습으로 이어지지 않음                         | 최근 퀴즈 오답과 탐험 오답을 우선 추천, 성공 기록에 따라 1~7일 복습 일정 | 복습 우선순위·오답 해소·한국 날짜 경계·전체 단어 학습 후 추천      |
| 매일 접속·높은 점수를 강요하면 부담이 됨                        | 하루 도장 하나, 누적 1/3/7/14일 배지. 연속 출석·감점·제한시간 없음       | 당일 반복 완료 도장 중복 없음, 쉬었다 온 날 누적 유지              |
| 휴대폰에서 정답 결과와 다음 문항을 보기 위해 반복 스크롤이 필요 | 정답 뒤 피드백으로 이동, 다음 단어는 듣기 버튼 위쪽으로 이동             | 실제 화면 확인과 viewport 검사                                     |
| 오답 사진에도 체크 표시가 붙어 정답처럼 보일 수 있음            | 성공한 사진에만 체크 표시, 오답은 따뜻한 재도전 안내                     | 오답 체크 아이콘 없음·진행 버튼 비활성                             |

## 실행

```sh
npm run test:content
npm run build
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm test -- tests/discovery.spec.ts tests/adventure-home.spec.ts tests/forest.spec.ts tests/adventures.spec.ts tests/soccer.spec.ts
npm run format:check
```

브라우저 검사는 데스크톱 Chromium과 iPhone 13 크기의 모바일 Chromium에서 수행한다. 실제 iPhone Safari의 음성 품질·음성 설치 상태까지 확인한 것으로 간주하지 않는다. 영어 음성이 없는 경우도 글 힌트로 학습 가능하다. 마이크를 켜거나 녹음·외부 전송·자동 발음 채점을 하지 않는다. 자기 확인 버튼을 실제 발음 평가 기록으로 표시하지 않는다.

탐험 기록은 기존 프로필과 같은 브라우저에 저장한다. 완료일은 최대 365개 보존하며 하루 포인트와 별개의 도장이다. 3단어 탐험은 기존 5문제 퀴즈 완료나 포인트를 대체하지 않는다. 복습 간격은 간단한 추천 규칙이며 학습 효과를 보장하는 평가 모델로 표시하지 않는다.
