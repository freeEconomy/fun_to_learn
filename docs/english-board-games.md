# Fun To Run 영어 보드 클럽

게임 메뉴의 **영어 체스 클럽**, **영어 오목 탐험**에서 마일로와 대국한다. 첨부한 체스 앱의 밝은 체크판, 말 이동 표시와 말풍선 안내를 참고하되 게임 아트·말 SVG·여우 안내 캐릭터는 새로 만들었다.

## 아이가 노는 방법

1. 체스는 내 흰 말과 이동 칸을, 오목은 빈 교차점을 고른다.
2. 영어를 듣거나 글을 읽고 정답을 고른 후 **이 수 두기**를 누른다. 틀려도 다시 고를 수 있고 힌트도 볼 수 있다.
3. 컴퓨터가 한 수 두면 다시 내 차례다. **한 수 되돌리기**, **다시 시작**, **두는 법**을 제공한다.
4. 연습은 영어 미션 4개, 도전은 6개가 목표다. 목표 후에는 대국을 이어가거나 **학습 모험 마치기**로 기록을 남긴다. 체크메이트·무승부·오목 승패로 끝난 대국도 기록할 수 있다.

체스는 말 이름과 생활 영어를 번갈아 배운다. 오목은 실제 놓을 돌의 연속 개수, 판의 왼쪽·오른쪽·가운데, 돌 색깔을 영어와 연결한다. 음성이 없어도 글로 정답을 고를 수 있다. 사전에서 단어를 누르면 기존 미국식 남성 Kokoro 음성을 재생한다. 새 보드 단어 14개의 MP3를 추가했고 기존 음성과 미디어 재생 경로를 유지했다.

## 규칙과 난이도

- 체스: 정상 초기 배치, 합법 수만 허용, 체크·체크메이트·스테일메이트, 캐슬링, 앙파상, 퀸·룩·비숍·나이트 승급, 반복·50수·기물 부족 무승부. 로컬 `chess.js` 엔진을 사용한다. 연습 상대는 다음 한 수를, 도전 상대는 내 응수까지 고려한다.
- 오목: 연습 9×9, 도전 11×11. 가로·세로·대각선의 5개 이상을 인정하는 자유 오목으로, 렌주 금수는 없다. 컴퓨터는 즉시 이길 수와 상대의 승리 수를 우선하며 도전에서는 열린 줄과 수비를 더 강하게 평가한다.
- 시간제한 없이 둔다. 영어 점수는 `50 + 첫 시도 정답 비율 × 50`이다. 힌트 사용은 첫 시도 보너스에서 제외한다. 되돌리면 해당 수의 영어 미션도 제거한다.

## 저장과 구조

완료 기록·최고 점수·하루 보상은 기존 `wordforest-english-v1` 프로필의 localStorage에 저장한다. `game:chess`, `game:gomoku`를 각각 하루 첫 완료에만 10포인트 지급한다. 기존 기록을 보존한다. 진행 중인 판은 화면을 나가거나 새로고침하면 초기화된다. 외부 DB, 외부 AI 대국 API나 유료 키는 필요 없다.

- `lib/forest/chess-game.ts`: 합법 수 엔진 어댑터·상대 탐색·대국 종료·되돌리기
- `lib/forest/vendor/`: 라이선스를 보존한 chess.js 0.13.4 원본과 타입 선언
- `lib/forest/gomoku-game.ts`: 오목 줄 판정·수비/공격 상대
- `lib/forest/board-learning.ts`: 판 상황에 맞는 영어 미션과 음성 목록
- `components/forest/adventures/board-games.tsx`: 공유 대국 화면과 접근 가능한 미션 대화상자
- `tests/board-games.test.ts`, `tests/board-games.spec.ts`: 규칙·음성·보상 단위 검사와 PC/모바일 대국 검사

브라우저 테스트의 음성 다운로드는 HTMLAudio의 정상적인 범위 요청(HTTP 206)도 확인한다. 실제 아이폰 하드웨어의 무음 스위치는 별도 기기 확인이 필요하다.
